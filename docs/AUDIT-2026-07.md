## 3. ÉTAT DES LIEUX — le créateur de template (LE cœur produit)

**Vision** (`architecture.md`) : un TEMPLATE = un `EditorDocument` v5 sauvé et paramétrable
(ou un fragment), **co-écrit par les agents** à partir d'une description NL + le **catalogue**
des briques/effets, puis **sauvé** pour être **ré-instancié** et amélioré.

### 3.A — Ce qui est construit et MARCHE (prouvé par tests offline)

- **Rail partagé solide** : `compile_shot.py` (seul producteur de prompts), `describe.py`
  (descripteur unique), `compile_spec.py::document_to_spec` (**effets = données IR** :
  countdown→`CountdownSegment`, nameplate→`NameplateSpec`, eye-open→`EyeOpenTransition`).
- **Catalogue vu par les agents (TPLM-A)** : `compositing/registry.py` (CONTRACTS génératif +
  REGISTRY montage) → `services/context.py::assemble_context` → `AgentContext.tools`/`.effects`
  → route `GET /api/catalog`.
- **Réalisateur NL → fragment v5 (TPLM-C)** : `crew/ports.py::DirectorAgent.assemble(description,
  part, effects, language) → FragmentPlan` ; impl Fake (intro CYOA déterministe) + OpenAI (JSON
  strict, ne pose QUE les effets du catalogue) ; `crew/assemble.py::fragment_to_bricks` (builder
  déterministe → `ClipBrick` v5, `ShotBrief` structuré, jamais de blob). Prouvé `tests/test_director.py`.
- **Atelier scène-par-scène (crew_room, câblé)** : contrat → brouillons → merge → révision,
  routes `POST /api/episodes/{id}/scenes/plan|next`, état persisté hors-doc.
- **Agents de raffinement câblés** : directeur artistique, dialoguiste, attaché de presse,
  producteur (brief) — agnostiques au format (prouvé `tests/test_crew_on_cyoa.py`).
- **Dispatcher de formats** : `services/formats.py::build_format_document` → même IR v5 (aventure #1, scènes #2).

### 3.B — Ce qui est ORPHELIN / STUB / INCOMPLET (le blocage)

1. **TPLM-C n'a AUCUN point d'entrée** : `DirectorAgent`/`FragmentPlan`/`fragment_to_bricks`
   n'apparaissent QUE dans `tests/`. Pas de `get_director_agent`, pas de route, pas d'usage
   dans `app.py`. La brique la plus importante de la vision est **débranchée**.
2. **Aucune persistance d'un document co-écrit comme template** : `TemplateRepo` ne connaît que
   des **slots vides** (`Template.structure_json` = `{kind,duration,aspect_ratio,resolution,narration}`),
   pas un `EditorDocument` v5.
3. **Aucune ré-instanciation** : rien ne recharge un `Template` en `EditorDocument`. Le bouton
   « Remplir avec l'IA » du front (`TemplateBuilder.tsx:184`) est un **stub** (`toast.info`).
4. **`FakeDirectorAgent`** rejoue une intro CYOA codée en dur (offline ne co-construit pas vraiment).
5. **Tables `template`/`prompt_template` absentes de `migrate.py`** (créées implicitement).

### 3.C — Écarts avec `architecture.md`

- **VIOLÉ** : « un TEMPLATE = un `EditorDocument` v5 sauvé » → le seul template persistable est
  une liste de **slots vides** (le « moule codé » que la règle refuse).
- **VIOLÉ** : « PAS un éditeur de montage vierge » → `TemplateBuilder.tsx` est exactement ça.
- **VIOLÉ (live)** : « les prompts se compilent, pas de 2e système » → `services/intro.py`
  concatène des prompts à la main et est **encore appelé** par `generation.py`.
- **Écart palette/IR** : `REGISTRY` montre aux agents des effets `montage.choice/facecam/narrate/
  subtitles` **non représentables en IR** (pointent vers des fonctions impératives) → un agent
  peut « voir » un effet qu'il ne peut pas poser.
- **OK** : le chemin réalisateur ne produit jamais de blob `shot=None` ; les agents lisent le catalogue.

### 3.D — Manques pour rendre « co-construire → sauver → ré-instancier » utilisable

1. Service `director` + route `POST /api/editor/documents/{doc_id}/parts` (miroir de `crew.py`) :
   `{description, part}` → `assemble_context("realisateur").effects` → agent → `fragment_to_bricks`
   → append au `EditorDocument`. **(Plus haut ROI, tout est prêt côté feature.)**
2. Refonte du stockage `Template` : `structure_json` (slots) → `document_json` (EditorDocument v5)
   + métadonnées de paramétrage + migration versionnée.
3. « Save as template » (depuis un doc/fragment) et « Instantiate template » (déterministe, nouveaux persos/idée).
4. Front : remplacer `TemplateBuilder` (slots) par une surface de co-construction (NL → revue
   briques v5 via `components/editor/` → save), câbler `/api/catalog`.
5. Fermer l'écart palette/IR (porter ou masquer les effets non-IR).
6. Converger/retirer `services/intro.py` (le fragment intro TPLM-C le remplace fonctionnellement).
